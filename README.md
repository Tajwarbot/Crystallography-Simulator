# Crystallography Simulator

The Crystallography Simulator is an interactive and educational web-based tool that allows users to visualize and explore key concepts in crystallography. From Miller indices to crystal structures, lattice systems, and defects, this simulator provides an intuitive way to understand complex topics in material science.

Try it out directly: [Crystallography Simulator Website](https://crystalsim.netlify.app).

## Features

### 1. Miller Indices Visualization
- Visualize crystallographic planes `(hkl)` and directions `[uvw]`.
- Interactive controls to modify indices and inspect the results.
- Analytical information, such as intercepts and directions, dynamically displayed.

### 2. Crystal Structures
- Explore common metallic crystal unit cells:
  - Simple Cubic (SC)
  - Body-Centered Cubic (BCC)
  - Face-Centered Cubic (FCC)
  - Hexagonal Close-Packed (HCP)
- Examine structural properties like atoms per unit cell, atomic packing factor (APF), and coordination number.

### 3. Seven Crystal Systems
- Visualize the geometries of all seven crystal systems:
  - Cubic, Tetragonal, Orthorhombic, Hexagonal, Rhombohedral, Monoclinic, Triclinic.
- Adjustable lattice parameters and angles for an in-depth understanding.

### 4. Crystal Defects
- Learn about various defects in crystal lattices, including vacancies and interstitial defects.
- Compare with a perfect crystal lattice.

### 5. Interactive Calculators
- Calculate planar density and visualize results for different crystal structures and planes.
- Understand key relationships in cubic structures.

## Usage

### Online
Access the simulator online without installation: [crystalsim.netlify.app](https://crystalsim.netlify.app).

### Local Setup
1. Clone the repository:
    ```bash
    git clone https://github.com/Tajwarbot/Crystallography-Simulator.git
    ```
2. Open the `Crystallography Simulator.html` file in any modern browser.

### Interactions
- **Rotate:** Click and drag with the left mouse button.
- **Zoom:** Scroll with the mouse wheel.
- **Pan:** Click and drag with the right mouse button.
- Dynamic tabs allow navigation between different simulation modes.

---

## How It Works

1. **Miller Indices:**
   Modify plane `(hkl)` or direction `[uvw]` values and observe 3D visualizations in real time.
2. **Crystal Structures and Systems:**
   Choose a structure or lattice system from a dropdown menu to simulate their properties and geometries.
3. **Interactive Calculators:**
   Input parameters like `(hkl)` values to compute planar density or atomic packing factors.
